# 🚀 Telegram Mini App & Business Bot

A full-featured Telegram bot with an interactive web interface (Telegram Mini App), an SQLite database, and an order management system. Developed in Python.

## 🛠 Tech Stack
- **Language:** Python (Flask, python-telegram-bot)
- **Frontend:** HTML5, CSS3, Telegram WebApp API
- **Database:** SQLite
- **Hosting:** Render (24/7)

## ✨ Key Features
1. **Interactive Mini App:** A convenient service catalog right inside Telegram with dynamic adaptation to the user's theme.
2. **Database:** Automatic saving of orders and users to SQLite.
3. **Cloud Hosting:** 24/7 service operation via a background Flask thread on Render.
